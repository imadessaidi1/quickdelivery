# quickdelivery-googlemaps-front

Front web Vue 3 de QuickDelivery.

## Installation
```bash
npm install
```

## Scripts principaux

### Développement
```bash
npm run serve
```

### Build
```bash
npm run build
```

### Lint
```bash
npm run lint
```

### Capacitor
```bash
npm run cap:sync
npm run cap:sync:all
npm run cap:sync:android
npm run cap:sync:ios
npm run cap:open:android
npm run cap:open:ios
```
